# Installer sur Android

Ouvre https://johunn.github.io/crafty-plus-app-preview/ dans Chrome sur Android. L’application est servie en HTTPS et peut être installée comme PWA ; ce n’est pas un APK.

1. Active Bluetooth et les services de localisation sur le téléphone.
2. Ouvre le lien dans Chrome, allume le CRAFTY+ et choisis Connecter.
3. Autorise l’accès Bluetooth. Autorise les notifications si tu souhaites l’alerte de batterie faible.
4. Dans le menu Chrome, choisis Installer l’application ou Ajouter à l’écran d’accueil.

Les données de suivi sont enregistrées localement dans le navigateur. Ne supprime pas les données du site si tu veux conserver l’historique ; exporte régulièrement le CSV.

Le site et son code source sont publics. La PWA ne garantit pas une surveillance Bluetooth ou des alertes lorsque Chrome est fermé ou suspendu par Android.
